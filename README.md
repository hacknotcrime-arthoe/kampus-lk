
# Кампус — личный кабинет студента

Прототип личного кабинета студента, разработанный для конкурса.
Решает проблему разрозненности студенческих сервисов: расписание, заявки,
успеваемость, СДО, общежитие, медпункт и чат с деканатом — в одном окне.

## Ссылка на прототип
https://твой-логин.github.io/kampus-lk/

## Стек
Чистый HTML/CSS/JS, без сборки и фреймворков. Данные — localStorage.
Пароли хешируются через Web Crypto API (SHA-256).

## Как запустить локально
Открыть `index.html` в браузере. Никаких зависимостей.
